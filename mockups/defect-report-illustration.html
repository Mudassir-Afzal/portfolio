Maker can approve own early-payment request when two signatures are required

High In review

Environment

Staging · Chrome (latest) · role: Maker + Checker (same user, two sessions)

Steps to reproduce

  1. Log in as maker.demo and create request REQ-DEMO for two eligible invoices.
  2. Submit the request for approval (1 of 2 signatures collected).
  3. Open the same request in the Approvals tab as maker.demo.
  4. Click Approve.

Expected result

Approve is disabled for the request's maker. The request stays at 1 of 2 signatures.

Actual result

Approve is enabled; the request moves to 2 of 2 and becomes eligible for disbursement. API returns 200 instead of 403.
